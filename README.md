# Folia Android

把 [folia-major](https://github.com/chthollyphile/folia-major) 打包成可在 Android 上直接安装的 App。

> 本项目只是 Android 端的移植与打包，播放器本身的代码、设计与版权归原项目 [chthollyphile/folia-major](https://github.com/chthollyphile/folia-major) 所有，遵循其 AGPL-3.0 许可证。非官方版本。

## 两个安装包，按需选择

| 安装包 | 说明 | 大小 |
| --- | --- | --- |
| `Folia-Android.apk` | **标准版**，不含模组功能，体积小、启动快 | 约 16 MB |
| `Folia-Android-Mods.apk` | **模组版**，内置模组商店，可在 App 内浏览、安装、更新、删除模组 | 约 24 MB |

两个包是独立的 App，可以同时安装，数据互不影响。日常听歌用标准版即可；想折腾模组再装模组版。

## 模组版有什么不同

- 右下角多一个「模组」按钮，打开是模组商店
- 商店只显示**安卓能运行**的模组：纯客户端、无 `main` 入口、排除 Windows/macOS 专属
- 支持在 App 内直接安装、更新、启用/停用、删除，不需要电脑
- 模组文件保存在应用私有目录，卸载 App 即清除

## 使用前提

- Android 8.0 及以上（arm64）
- 网易云音乐相关功能需要配合一个本地 API 服务使用（单独的服务 App，不在本仓库内）
- 首次启动需要授予通知权限（用于媒体控制通知）

## 安装

1. 下载对应 APK
2. 允许「安装未知来源应用」
3. 安装后打开即可

## 说明

- 前端代码保持原样，Android 端只增加了打包外壳、媒体会话桥接与（模组版的）模组商店插件
- 模组生态来自 Folia 社区市场，模组本身由各自作者维护
- 本项目不提供任何音乐内容，仅作为客户端使用
